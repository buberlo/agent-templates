# Grok Bot

1. **Bot bio** from **Purpose** + **When to use** (compact English).
2. **Skill:** **System prompt**, **Workflow**, **Basic examples** (as training hints).
3. **Connect Apps / MCP:** Public HTTPS endpoints or **command on the bot box** only — no user-localhost or VPN-only targets. Custom MCP: no secrets in command `argv` (shared bots).
4. **Tool policies:** Allow / auto-review / needs approval / blocked; respect skill ceiling (wiki).
5. **Tokens** stay on the connector backend, not in chat.
