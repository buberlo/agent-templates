# Grok Bot

1. **Bot-Bio** aus **Zweck** + **Wann nutzen** (Deutsch, kompakt).
2. **Skill:** **System-Prompt / Instruktionen**, **Arbeitsablauf**, **Grundbeispiele** (als Trainingshinweis).
3. **Connect Apps / MCP:** Nur öffentliche HTTPS-Endpoints oder **Command auf der Bot-Box** — kein User-localhost, kein VPN-only. Custom MCP: keine Secrets in Command-`argv` (geteilte Bots).
4. **Tool-Policies:** Allow / Auto-review / Needs approval / Blocked; Skill-Ceiling beachten (Wiki).
5. **Tokens** auf Connector-Backend, nicht im Chat.

Plattform-Details: `domains/agent-platforms/grokbot/_category.md`.
